# Pegline 2.6.1 发布说明

发布日期：2026-11-13
产物：`dist/Pegline-2.6.1-win-x64.zip`（单文件 exe + README + LICENSE + CHANGELOG）。
`target\release\pegline.exe` 为 **1,920,512 B（1.92 MB）**，ProductVersion
`2.6.1.0`。

## 2.6.1 修复

**夹子拖拽时不再弹出底部预览。**

按住一张挂图的夹子拖动时，底部本来只应在普通悬停 0.35 s 后出现的大预览
会提前显示，并在拖动过程中挡住画面。原因是夹子按住后 UI 仍把卡片算作
`hover`，而预览只检查 `hover`。

现在的行为：

- 夹子按住/拖拽期间，UI 不再把卡片报成 hover，`update_preview` 会立即隐藏
  预览并重置预览状态。
- 拖拽中才完成的预览解码（异步线程）会被丢弃，不会在松手前突然出现。
- 松手后恢复正常：指针停在卡片上仍会按原来的 0.35 s 延迟显示预览。
- 夹子的高亮、缩放、光晕、拖拽、挤压、交换和顺序持久化都不变。

## 自 2.5.1 以来的主要变化（2.6.0）

### 夹子拖拽与线内重排

- 指针移到挂图的夹子上：夹子放大到 1.12 倍、加暖白光晕、金属提亮；卡片本身
  不抬起、不出按钮行。
- 按住左键拖动：水平 1:1 跟手，带 0.075 s 弹簧的轻微滞后和松手后的惯性回槽；
  Y 轴有回绳力（0–18 DIP 线性，之后 0.22×，上限 26 DIP），夹子始终留在挂绳附近。
- 向右拖时右侧邻卡被挤压（位移 + 最多 3° 旋转）；穿透达到 28 DIP 并持续
  60 ms 后，邻卡弹向左侧并与被拖卡交换槽位；向左拖对称。
- 交换后被拖卡仍跟随指针，会短暂叠在邻卡上方，松手才归位；180 ms 冷却和
  43 DIP 回撤阈值避免在边界抖动。
- 松手后顺序写入 `pegged.txt`；顺序真的变化才写，并播一次 `Tink`。
- 单击夹子（移动 <4 DIP）是无操作；长按、双击和 OLE 拖出不会被误触发。

### 纸片摆动、柔性

- 每张卡按尺寸计算有效摆长 `L_eff=(w²/12+h²/3)/(h/2)`（60–220 DIP），
  横卡、竖卡、方卡和便签的周期不同。
- 阻尼由线性项和二次空气阻力组成；正常拖拽/交换只过冲一次，约半秒停住，
  不再像铁块那样来回 2–3 次。
- Y 轴下落会改变有效重力，横向加速度驱动摆角；另叠加最多 ±1.2° 的柔性剪切，
  顶边和夹子不动、底边轻微滞后。
- 交换小跳只有 6 DIP，不再明显向上弹起。

### 高宽比与相对风

- 每张卡按 `aspect=h/w` 推导线性阻尼、二次阻力和风增益；竖长纸片更“兜风”。
- 压心在夹子下方 `r=h/2`，相对风扭矩直接加进摆角加速度，所以匀速拖动时卡片
  会稳定地略微向后倒，而不是永远竖直。
- 当前“更强空气”预设：线性阻尼 `1.116 + 0.434·tall`，二次阻力
  `0.279 + 0.31·tall`，风增益 `4.34e-5·(0.7+0.6·tall)`。

### 调参工具

- `tools/paper-sim.html`：单文件 SVG 调参器，拖动夹子、实时滑块、预设、
  角度/角速度曲线和参数 JSON 复制；无外部依赖。
- `PEGLINE_PAPER_TRACE` + `tools/paper-trace.ps1` + `tools/paper-plot.py`：
  逐帧 CSV 和角度/角速度/线速度图，用于精确比较峰值、过零和停稳时间。
- 调参说明见 `docs/PAPER-TUNING.md`。

- `cargo test`：255 个 lib 测试 + 1 个 main 测试通过（1 ignored）。
- `cargo clippy --all-targets -- -D warnings` 与 `cargo fmt --check` 通过。

- `tools/paper-sim.html` 内联脚本通过 `node --check`。
- 200% DPI、6016×420 probe：60.16 fps，draw p50 0.585 ms / p95 0.915 ms，
  private 98.4 MB（基线 60.10/60.06 fps、0.658/0.660 ms、97.1–97.4 MB）。
  这些数字来自 2.6.0 的空气阻力版；2.6.1 只改了 UI 预览抑制，没有改渲染路径。

## 已知限制

- 空气阻力仍是经验模型：没有平移阻力对 x/drop 的反馈、升力/涡脱落/附加质量
  或逐顶点弯曲；`wind_gain` 不是 `0.5ρCdA`。
- 120 Hz、第二显示器、睡眠/唤醒和 100% DPI 的夹子截图仍未在真实硬件上实测。
- 交换后被拖卡与邻卡短暂重叠约 98 DIP 是设计选择，松手后归位。
- 夹子拖拽只重排线内顺序，不创建文件、不调用 `DoDragDrop`；拖到其他应用仍是
  原来的 OLE 拖出。

## 安装

1. 下载 `Pegline-2.6.1-win-x64.zip`，解压到任意目录。
2. 运行 `pegline.exe`；程序从托盘启动。
3. 按 **Ctrl+Alt+K** 截图，截图会挂到屏幕顶部的晾衣绳上。

设置、便签和线序保存在 `%APPDATA%\Pegline` 与 `%LOCALAPPDATA%\Pegline`。
