发布日期：2026-11-12
产物：`dist/Pegline-2.5.0-win-x64.zip`（单文件 exe + README + LICENSE + CHANGELOG）

`pegline.exe` 为 **1,878,528 B（1.88 MB）**，ProductVersion `2.5.0.0`（2.4.2 的 1,840,640 B

## 2.5.0 新功能

便签编辑器可以按需变大了，并且每个便签记住自己的大小。

1. **缩放**：拖动纸面的右边缘、下边缘或右下角，纸面在 **460×360 ～ 820×640 DIP**
   之间实时变化，窗口随纸面向右下生长，左上角不动。纸张、折角、阴影、文字排版、
   选区和滚动位置都跟着更新；只有宽度变化才重排文字，仅改高度只是重新夹紧滚动。
   拖到工作区边界即停；左边缘、上边缘和左下角不可拖，也不能移动窗口。
2. **悬停反馈**：指针停在可拖动的边或角上时，该边显示 2 DIP 的系统高亮色
   （`COLOR_HIGHLIGHT`），光标变成水平/垂直/斜向双向箭头。高亮画在窗口层，
   不进入纸面位图，所以文字仍是 ClearType，返回飞行也不带高亮。
3. **尺寸记忆**：拖完松手即写入 `settings.ini` 的 `noteSize:<文件名>=宽x高`
   （整数 DIP）。下次编辑同一个便签按这个尺寸打开；拖回默认 460×360 时删除该键，
   归档时也删除；新建便签在文件创建成功后才记尺寸，空文本丢弃的便签不记。
   值损坏或超出范围时按默认尺寸打开并把合法范围内的值夹紧。
4. **DPI / 工作区**：编辑期间换显示器或工作区变化时，按记住的尺寸重新定位，
   不会跳回 460×360；工作区太小（连 500×400 都放不下）时纸面缩到能容纳的最大值、
   窗口铺满工作区，内容仍在内部滚动。

## 实现要点

- 手写 `SetCapture` + `SetWindowPos` 缩放，不用 `WS_THICKFRAME`：系统边框会加 1 px
  非客户区和系统阴影，模态 sizing 循环还会与鼠标钩子、IME 和提交逻辑重入。
- 阴影改为 **9 宫格图集**：只在 DPI 变化时烘焙一次（角 48 DIP、边中 8 DIP），
  缩放时只更新 9 个目标矩形，不再整窗重烘。
- 悬停高亮走 `Command::Hover(Option<ResizeZone>)`，只在边变化时发一次。
- 打开/提交飞行的位图按当前纸面渲染，长边 2048 px 封顶；空便签丢弃不再在 UI
  线程上渲染 460×360 的返回图。

## 测量（release，200% DPI，3008×1692）

| 场景 | private | draw p50 | draw p95 |
|:--|--:|--:|--:|
| `probe --mode=note` 460×360 | 56.5–57.3 MB（终版 57.0） | 0.22–0.25 ms | 0.25–0.32 ms |
| `probe --mode=note` 820×640 | 72–72.8 MB（终版 72.3） | 0.20–0.22 ms | 0.23–0.28 ms |
| 应用内 820×640 打开编辑器 | 170.9 MB（WS 193.9） | — | — |

- 20/40/100/200 次 MAX↔MIN 往返漂移 9–15 MB，是一次性高水位（最大纸面位图
  9.4 MB + D2D 缓存），不是每周期泄漏：1/2/3/5/10/20/40/100/200 周期 =
  11.0/13.9/14.1/14.1/14.0/14.1/14.6/14.4/15.8 MB。
- 真实鼠标拖动：UI `handle_us_p50 ≈ 1.5 ms`，渲染 `draw_us_p50 ≈ 0.3 ms`。

## 已知限制

- 不能移动编辑窗口，不能从左/上边缘缩放，没有键盘/触摸缩放。
- 尺寸按文件名记忆；改名后回到默认尺寸（孤儿键不扫描）。
- 悬停预览固定 408×264 DIP，不随编辑尺寸变化。
