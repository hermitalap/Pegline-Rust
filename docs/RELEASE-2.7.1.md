# Pegline 2.7.1 发布说明

## 2.7.1 变更

**便签进出编辑器时，那圈 4 DIP 的玻璃边框不再跟着纸面飞完全程。**

边框属于晾衣绳上的卡片，不属于编辑器的纸面——编辑窗口里那张纸本来就没有边框。现在：

- **去程**（点便签 → 编辑窗口）：边框在路径的前 1/3 淡出（约 0.14 s），不再一路贴在纸面边缘
  飞到编辑窗口上、落地后才随飞行层一起消失。
- **回程**（保存或关闭 → 绳上的卡片）：飞行第一帧不再带边框，边框只在路径的后 1/3 淡入
  （约 0.25 s），落到卡片上之前就长回来了。
- **丢弃空便签的翻滚**：全程画裸纸，不再从编辑器切换过去时闪一下边框。
- **纸面圆角随飞行过渡**：卡片纸面是 12 DIP、编辑器纸面是 22 DIP，途中按同一路径进度插值，
  落地帧仍与编辑窗口的纸面对齐，起飞帧仍与卡片纸面对齐。

淡出淡入按**缓动后的路径进度**计算，而不是按时间：飞行用的是 CSS `ease` 曲线，前段走得快，
按时间切会切在一个肉眼可见的错位位置。

截图飞行和标注编辑器往返**没有任何变化**（逐帧导出比对为 0 差异），夹子仍然只在回程末段出现。

## 验证

- 226 个 lib 测试 + 1 个 main 测试通过（新增 3 个：便签边框的路径淡出/淡入、截图飞行的边框淡入
  不变、纸面圆角过渡）；`cargo clippy --all-targets -- -D warnings` 与 `cargo fmt --check` 干净。
- 仓库外副本用审计同一套逐帧导出器对比 2.7.0：截图飞行与标注编辑器开关 31 个数值列**逐帧差 0**；
  四条便签路径的纸面矩形**逐帧差 0**；去程边框在 t = 0.150 s 跌破 0.01，回程在 t = 0.267 s 升过 0.01。
- `probe --mode=line`：60.04 fps，p50 16.67 / p95 17.01 ms，draw p50 0.624 / p95 0.914 ms，
  private 97.4 MB；`--mode=flight`：60.40 fps，private 94.4 MB。与 2.7.0 的 60.00 / 0.820 / 97.3
  在 5 % 以内。
- `pegline.exe` 1,886,208 B（CI 构建；2.7.0 为 1,885,184 B）。

## 已知限制

- 120 Hz、第二显示器和睡眠/唤醒仍未实测。
- 便签回程的起点仍是编辑器纸面外扩 4 DIP 的卡片矩形：不再画边框之后，这 4 DIP 只体现在纸片的
  起始位置上，肉眼看不出来；若要让首帧与纸面像素级重合，需要另开一项把起点改成纸面本身。
- 标注编辑器的往返**仍然全程保留完整的玻璃边框**——它的卡片本来就带边框，去掉会看成闪一下。
- `docs/VISUAL-TESTS.md` 里便签飞行的三行相关截图标记为「待截图」：旧图拍的是旧行为。

## 安装

1. 在本页 Release 资产中下载 **`pegline.exe`**（单文件，无需解压）。
2. 把它放到任意目录，双击运行；程序从托盘启动。
3. 按 **Ctrl+Alt+K** 截图，截图会挂到屏幕顶部的晾衣绳上。

设置、便签和线序保存在 `%APPDATA%\Pegline` 与 `%LOCALAPPDATA%\Pegline`。
