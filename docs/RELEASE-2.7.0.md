# Pegline 2.7.0 发布说明

## 2.7.0 变更

**动画不再在阶段切换处“断电”。** 之前有五个切换点会把速度直接丢掉或硬跳，现在都从当前速度继续：

- **收起线带**：收到一半再移回指针，不再硬停；切换帧的速度差从 100 % 降到 19 %。
- **阵风轻摆**：缓动起步从 12.16 °/s 的跳变降到峰值的 4.6 % 以内；每次阵风后的停稳时间从 4.67 s 缩到 4.05 s。
- **拖拽松手**：4° 的拖拽倾斜直接并入摆动弹簧，不再先清零再摆；松手瞬间的姿态抹平从 2.57° 降到 0.18° 以内。
- **便签飞出**：从悬停位置飞回时继承飞入的末速，第二帧保留的速度从 0.2 % 提到 55.9 %。
- **卡片掉落**：第一帧与线缆上的姿态逐角点一致（误差 33.4 → 0 DIP），不再先跳一下再落。

**掉落曲线改为 `e = t²`。** 前 160 ms 走 49–54 DIP（原来 22–28），末端加速度回到 1× 重力（原来 4.51×），看起来是“掉下去”而不是“被按下去”。

**飞行改用 CSS `ease` 曲线**（`cubic-bezier(0.25,0.1,0.25,1)`）。前 100 ms 走 19–26 %（原来 1.5 %），起飞跟手、落地变缓；双击图片打开标注编辑器时的预卷从 233 ms 缩到 67 ms。

**拖拽幽灵（拖动时跟着指针的小窗）改为帧间跟随。** 空闲唤醒 30.8 → 16.4 ms，60 Hz 上的重复帧 66.7 % → 1.0 %；750 DIP/s 快速扫掠时指针误差 p95 9.9 DIP。

**便签悬停更稳。** 线带重排后入口位置每拍刷新，悬停便签不再停在旧位置（指针距离 338.7 → 16.4 DIP）；淡入淡出与刷新率无关。

**唤醒帧不再吃掉 50 ms。** 从空闲或托盘唤回时，第一帧的 dt 回到 1 拍；帧率上限不低于显示器刷新率时自动等同 auto，60 Hz 屏选 120 不再自锁到 55 fps。

**落地镜像。** 飞行副本与真实卡片的落地轻摆使用同一条曲线，0.16 s 淡出期间两张图不再分离。

## 验证

- 223 个 lib 测试 + 1 个 main 测试通过；`cargo clippy --all-targets -- -D warnings` 与 `cargo fmt --check` 干净。
- `probe --mode=line`：60.00 fps，p50 16.66 / p95 16.93 ms，draw p50 0.820 / p95 1.291 ms，private 97.3 MB。
- `probe --mode=flight`：60.39 fps，private 94.6 MB。
- 仓库外副本用审计同一套导出器复测 15 处修改：7 处达成、8 处部分，逐条改前/改后数字已随修复记录归档；独立复核 0 阻断。
- `pegline.exe` 1,885,184 B（2.6.2：1,903,104 B）。

## 已知限制

- 120 Hz、第二显示器和睡眠/唤醒仍未实测。
- 静止起步的阵风曲线与 2.6.2 相差至多 0.94°：起点速度连续与逐帧相同不可兼得，取舍见 `docs/DECISIONS.md` D19。
- 收起→展开方向在 60 Hz 仍有 38 % 的速度跳变（展开走弹簧、收起走缓动的结构所致）。

## 安装

1. 在本页 Release 资产中下载 **`pegline.exe`**（单文件，无需解压）。
2. 把它放到任意目录，双击运行；程序从托盘启动。
3. 按 **Ctrl+Alt+K** 截图，截图会挂到屏幕顶部的晾衣绳上。

设置、便签和线序保存在 `%APPDATA%\Pegline` 与 `%LOCALAPPDATA%\Pegline`。
