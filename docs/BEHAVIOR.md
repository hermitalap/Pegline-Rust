# Pegline 行为规范（WPF 版逐条移植依据）

这份文档描述 **用户能看到、能感觉到的全部行为**，是实现 Rust 版时的唯一验收依据。
所有数值来自 `archive/wpf-v1/src`，坐标系与常量在 §2、§3 给出。实现细节可以不同，
行为必须一致；确有必要改变的地方，在 `docs/DECISIONS.md` 里单独记录。

> 阅读顺序建议：§1 → §3 → §4（线带）→ §5（卡片）→ §6（飞行）→ §9（截图链路）。

---

## 1. 产品一句话

截图挂在屏幕顶部的晾衣绳上。指针顶到屏幕上沿，绳子滑下来；移开，绳子收回去。
截图从被截取的位置飞上绳子；可以复制、打开、标注、拖进文件夹保存、拖进回收站丢弃。
便签可以直接在纸面上写 Markdown：光标行是源码，其余行是排版后的样子。

## 2. 坐标与 DPI

- 进程清单声明 **Per-Monitor V2** DPI 感知；启动时再用 `SetProcessDpiAwarenessContext` 兜底。
- **窗口外的一切（指针、屏幕、截图区域、卡片框）用设备像素**；**窗口内的布局用 DIP**，
  每个窗口按所在屏幕的缩放比换算（`scale = dpi / 96`）。
- 线带窗口的尺寸：`工作区宽度 × ceil(210 * scale)` 设备像素，位于工作区左上角。
- 窗口内容通过 `LayoutTransform = scale(window_scale / wpf_dpi)` 校正；Rust 版不需要这层，
  直接把设备像素和 DIP 的换算收敛在场景层。

## 3. 常量总表

### 3.1 线带与卡片（DIP）

| `ActionsGap` | 6 | 按钮行与卡片间距 |

### 3.2 动画（秒、度、DIP）

所有时间都以秒计，与帧率无关：同样的参数在 60 Hz 和 120 Hz 上应给出同样的手感。
弹簧按真实 `dt` 积分（内部 1/240 s 子步），时间线按真实时间推进，不能按帧数计数。

| 名称 | 值 |
|:--|:--|
| 线带下滑弹簧 | response 0.42, damping 0.82 |
| 线带收起 | 0.22 s，`hideT²` 缓入，目标 `-(210+12)` |
| 卡片水平弹簧 | response 0.55, damping 0.78 |
| 落卡弹簧 | response 0.42, damping 0.72，初始 -46 |

| 摆动弹簧 | `(1, 1)` 起步，落定后 stiffness 46 / damping 2.6；被风拨动后 38 / 2.4 |
| 按压缩放 | response 0.3 / damping 0.6；按住时 0.45 / 1.0；目标 1.035（悬停）、0.95（按住） |
| 卡片倾斜 | 随机 ±2.5°，创建时固定 |

### 3.3 颜色与字体

- 相框玻璃：`#B8F7F7F7`；边框：线性渐变 `#E0FFFFFF → #40FFFFFF`（90°）；
  相框阴影：黑色，模糊 20，偏移 5，不透明度 0.18（悬停 28 / 8 / 0.26）。
- 按钮：同样玻璃底、1 px 边框、圆角 13、阴影 8 / 2 / 0.18；悬停底色 `#F2FFFFFF`。
- 文字：`#1E1E1E`，13 px；所有非符号文字统一用 `Microsoft YaHei UI` Medium
  （含中文、英文、西语）。“✓ 已复制”的勾选是 U+2713 字符，便签色点的勾是
  画出来的两条线。
- 绳子：核心 `#8C8C8C` 1.2 px；白色高光 `#73FFFFFF` 0.4 px（上移 0.35）；
  阴影 `#38000000` 1.4 px（下移 1.2，模糊 2.4）；两端 8% 内淡入淡出。
- 便签四色（纸、边、墨）：黄 `FFF4B8/F6E288/4A3B12`、蓝 `DBF1FF/BAE1F9/12384A`、
  粉 `FFE1E8/F8C4D2/4A1828`、灰 `F2F2F2/DADADA/282828`。
- 界面字体：统一 `Microsoft YaHei UI`；只有撤销/重做两个箭头符号保留
  `Segoe UI Symbol`，工具图标是矢量绘制。便签正文也用 `Microsoft YaHei UI`。
- ClearType 策略：不透明表面（标注窗口的工具栏/画布、快捷键窗口）用
  `ClearType`；线带覆盖层是逐像素透明表面，只能用灰度抗锯齿；便签先做 3 倍
  超采样再缩放，也用灰度以免子像素条纹被重采样成彩边；标注保存的 PNG 带
  alpha，固定用灰度，避免文件里出现彩色边缘。

## 4. 线带窗口

### 4.1 窗口属性

- 无边框、`AllowsTransparency`（逐像素透明）、置顶、不进任务栏、不抢焦点
  （`WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`），`WM_MOUSEACTIVATE → MA_NOACTIVATE`。
- 默认 `WS_EX_TRANSPARENT`（点击穿透）；只有指针在照片上或正按住卡片时才取消穿透。
- 位置：指针所在屏幕（或指定屏幕）的工作区顶部，横跨整个工作区宽度。

### 4.2 显示 / 隐藏

`wanted` 表示“有东西可看且没被全屏应用挡住”。

- `wanted && !FullScreen → Show()`；否则 0.4 s 后 `Hide()`。
- `line.Revealed` 表示绳子是否放下；只影响内容位移，不影响窗口显隐。
- 全屏检测：前台窗口矩形覆盖该屏幕边界，且类名不属于
  `Progman / WorkerW / Shell_TrayWnd / Shell_SecondaryTrayWnd`，也不是桌面/Shell 窗口。

### 4.3 放下与收起

30 Hz 轮询指针（`GetCursorPos`）：

- 指针在屏幕顶部条（工作区顶部到屏幕顶部，至少 2 px）内，且未被本次点击抑制、
  没有按住鼠标、没有全屏应用 → 计时 0.3 s 后放下。
- 放下时若指针在另一块屏幕，线带先移动过去并重算容量。
- 指针离开“线带区域（线带下沿到屏幕顶部）”，且不忙（见下）→ 0.5 s 后收起。
- 忙：钉住（快捷键/托盘打开）、拖拽中、菜单打开、按住卡片、截图后 2.5 s 展示期内。

### 4.4 点击顶边

低层鼠标钩子（`WH_MOUSE_LL`）监听任意屏幕顶部条的左/右键按下：

- 置 `bandSuppressed = true`，指针离开顶部条后清除。
- 若线带正放下且点击处不是照片 → 取消钉住并立即收起。

### 4.5 钉子（pin）

- 快捷键/托盘打开：`pinned = true`，指针进入线带后第一次离开时解除（进入即 `pinned = false`）。
- 关闭线带时清空 `pinned`、`peekUntil`、`HoverId`。

### 4.6 空线带

- 没有卡片时，在线带中央显示提示“截一张图，它就会挂在这里”，透明度随卡片数量淡入淡出。
- 每次启动：线带落下并保持 2.5 s，让用户看到应用已启动；期间指针不在线带内也保持，
  到点后按正常收起延迟收回。首次运行延长到 5 s，并显示空提示。

## 5. 卡片

### 5.1 结构（自下而上）

1. 相框 `Border`：玻璃底、渐变边、圆角 16、阴影。
2. 照片 `Image`：内缩 4，圆角 12，等比填充；位图缩放模式 HighQuality（WPF 值）。
3. 左上角丢弃叉：20×20，玻璃圆底 + “×”，悬停淡入，点击立即丢弃。
4. 夹子：9×26，位于槽位水平中心、顶部；随卡片一起旋转；渐变金属 + 槽 + 小阴影。
5. “✓ 已复制”标签：玻璃胶囊，复制后 1.2 s 内在按钮位置显示。
6. 按钮行：复制 / 打开，悬停出现；出现时“已复制”让位。
7. 便签色板（仅便签）：4 个 15×15 圆点，悬停出现，当前色打勾。

### 5.2 运动

- 水平位置由弹簧逼近槽位；倾斜 = 摆动弹簧值 + 固定随机倾斜。
- 飞行中的卡片不在线上：透明度 0，也不参与命中测试；由飞行窗口绘制，落地时才出现。
- 飞行落点在现有最右卡片右侧一整格（最终槽位 + 87 DIP），落定后整排（含新卡）
  向左 87 DIP 弹簧回中，卡片间距不变。
- 落地交接：真实卡片落地即不透明，并在同一帧开始回中弹簧和 2.2° 轻摆；飞行窗口
  在 0.16 s 内镜像同一 x 弹簧与摆角、叠加固定倾斜后淡出，所以两张图始终对齐。
  飞行窗口的夹子在 frame top 上方 14 DIP，旋转中心也在这里，与线上卡一致。
- 吊挂下落：新建卡片（非飞行到达）从 -46 弹到 0，透明度随之淡入。
- 飞行到达的卡片落地时处在飞行落点，只轻摆 2.2°，随后随整排回中。
- 卡片被按下时缩到 0.95，悬停放大到 1.035。
- 卡片整体透明度：飞行中/掉落中为 0；未到位为 0；飞行到达的卡片落地即 1；
  其余按 0.16 s 时间常数淡入。
- 拖动中的卡片相框半透明（0.45），叉和按钮隐藏。

### 5.3 悬停

- 指针在卡片命中框（含按钮区域扩展）内 → `HoverId`。
- 悬停时显示叉、按钮行；便签显示色板。
- 悬停 0.35 s 后显示大图预览（§7）。

### 5.4 命中框

- 卡片框：`x = X - cardW/2`，`y = RopeY(X) - 9.5 + drop + 14`，尺寸 = 相框尺寸。
- 悬停时向下并入按钮行（宽度取按钮行/色板较大者）。
- 命中测试在 DIP 下进行，外扩 10 DIP 作为容差。

## 6. 飞行与掉落

### 6.1 起飞

- 起点：截图区域（设备像素），若最长边 > 1600，按中心缩到 1600。
- 终点：卡片落点矩形（设备像素）。
- 窗口：`起点 ∪ 终点`（再并入落地后回中的最终槽位）各边外扩 `60 + 5% * max(宽, 高)`。
- 照片：起飞前按 1600 解码，`Linear` 缩放。

### 6.2 过程

- `k = InOutCubic(t / 0.65)`；宽度/高度线性插值；中心点线性插值；
  `topY` 再减去 `sin(πk) * 30` 的弧。
- 相框/夹子的不透明度按 `Smooth(raw, 0.10, 0.55)` 淡入。
- 阴影只在宽度 ≤ 300 DIP 时挂上（预烘焙或实时都行，但必须避免每帧重新模糊）。
- 结束时回调“落地”：真实卡片已经是不透明底图，飞行窗口在 0.16 s 内镜像它的
  回中弹簧与 2.2° 摆动并整体淡出；落地后飞行窗口关闭自己的阴影，阴影只保留
  真实卡片下面那一份。

### 6.3 窗口复用

- 飞行窗口池化复用；飞行结束后隐藏，并把窗口缩到 2×2 交还表面。
- 下一次飞行重新 `Place` 到新的包围盒；绝不能闪上一张图（布局必须在 Show 之前完成）。

### 6.4 掉落

- 从卡片当前位置开始，加速度 `e = k³`，垂直下落 200 DIP，倾角保持卡片原有的
  `tilt` 不再增大（旋转只会把卡片甩向一侧），透明度 `1 - e`，0.32 s 结束。
- 掉落期间真实卡片不可见；0.6 s 后从列表移除并通知。

## 7. 悬停大图预览

- 触发：同一张照片连续悬停 ≥ 0.35 s；换卡、缩略图变化、文件写入时间变化都会重新计时。
- 位置（全部设备像素）：
  - 工作区四周留 12*scale 边距；预览与卡片间距 12*scale。
  - 优先放在卡片下方；下方放不下则放上方；都放不下则不显示。
  - 最大 900×650 DIP（按屏幕缩放），扣除 6 DIP 内衬后等比缩放源图。
  - 水平居中于卡片，并夹在工作区内。
- 解码：只在 worker 上按“显示尺寸”解码，不放大源图。
- 窗口：透明、置顶、不抢焦点、点击穿透、不显示在任务栏。
- 关闭：指针离开、任何按键按下、拖拽、菜单、线带收起、屏幕切换、文件消失、图片被编辑。
- 预览图在隐藏时必须释放（内存）。

## 8. 手势

| 手势 | 行为 |
|:--|:--|
| 单击 | 复制（图片 + PNG + 文件路径三种格式） |
| 双击 | 用默认程序打开文件 |
| 长按 0.45 s | 编辑：图片用画图（`mspaint`，失败退回 `edit`），便签打开 WYSIWYG 便签编辑器（§10.1） |
| 拖拽 > 4 DIP | `DoDragDrop(Copy | Move)` + 自绘拖拽预览 |
| 右键 | 上下文菜单 |
| 点叉 | 丢弃（自己的文件进回收站；外部文件只下绳） |

### 8.1 拖拽语义

- 应用接收 → 发一份副本，图留在绳上。
- 文件夹/桌面接收 → 资源管理器执行移动，文件离开，图下绳。
- 回收站 → 删除。
- 没有目标接收 → 图留在绳上。
- 拖拽结束后立即、0.6 s、1.5 s 各清理一次（等资源管理器完成移动）。

### 8.2 右键菜单

复制 / 打开 / 标注（图片）或编辑（便签） / 在资源管理器中显示 /
（自己的文件）保存到桌面 / 分隔线 /（自己的文件）丢弃（图片）或归档（便签），
否则“取下”+“移到回收站”。

图片的“标注”直接打开 §11 的标注窗口，保存后覆盖原文件并原地刷新卡片；
取消不改动文件。便签的“编辑”打开 §10.1 的 WYSIWYG 编辑器；便签的
“归档”把文件移进 `Notes\Archive`，不删除。

菜单打开前把线带窗口设为前台，菜单关闭后复位。

### 8.3 复制

写入剪贴板：完整图片、`PNG` 格式流、文件拖放列表。写入后 `Flush`（重试到成功或放弃）。
复制期间忽略下一次剪贴板通知，避免自己的复制被当成新截图。

## 9. 截图链路

### 9.1 文件监听（Win+PrtScn）

- 监听已知文件夹 `FOLDERID_Screenshots`（不是硬编码“图片\Screenshots”）。
- 文件夹不存在时每 3 s 轮询，出现后开始监听。
- 启动时已存在的文件记为“已知”，不触发挂卡。
- 事件去抖 0.25 s 后扫描；只认 png/jpg/jpeg/bmp/gif/tif/tiff，忽略隐藏文件和
  `thumbs.db`、`desktop.ini`、`.ds_store`。
- 新文件必须可读（长度 > 0），否则下次重试。
- 每个新文件：读像素尺寸 → 判断是否 3 s 内新鲜 → 推断截取区域 → 挂卡/飞行。

### 9.2 剪贴板（Win+Shift+S、PrtScn）

- `AddClipboardFormatListener`；收到 `WM_CLIPBOARDUPDATE` 后静默 0.15 s 再读。
- 忽略自己写入的剪贴板（1 s 窗口）和没有“只有图片”的内容：
  带 HTML、UnicodeText、FileDrop、RTF 的都不算截图。
- 优先 `PNG` 格式；否则 `Clipboard.GetImage()`。
- 32 位图若 alpha 全 0 视为不透明（转 BGR32）。
- 内容哈希 10 s 内重复 → 忽略。
- 存到 `%LOCALAPPDATA%\Pegline\Screenshots`，文件名 `截图 yyyy-MM-dd HHmmss.png`
  （按语言本地化“截图/Captura/Screenshot”），重名加序号。
- 编码 PNG 在 worker 线程；完成后挂卡。
- 与文件截图一样，能推断出截取区域时从该区域起飞（§6.1）；推断不出就直接挂上。

### 9.3 截取区域推断 `Guess(w, h, foreground, fromPointer)`

1. `w < 3 || h < 3` → 无。
2. 与某块屏幕尺寸差 ≤ 2，且该屏幕包含指针 → 该屏幕工作区。
3. 与虚拟桌面尺寸差 ≤ 2 → 指针所在屏幕。
4. 与前台窗口矩形差 ≤ 20 → 该窗口矩形（水平居中到截图宽度）。
5. `fromPointer == false` → 无。
6. 否则以指针为右下角、`w×h` 的区域；必须在虚拟桌面内，否则无。
7. 无区域 → 不飞，直接落地。

### 9.4 双胞胎合并

- 8 s 窗口内，一份来自 Pegline 收件箱、另一份来自外部（Windows 保存），
  且画面内容相同（见 §12）→ 保留 Windows 那份，删除收件箱副本，卡片改指向。
- 两个 worker（剪贴板解码、文件夹监听）可能同时判定、互相看不见，所以挂卡前
  UI 线程还会做一次兜底：找线上另一来源、同像素尺寸、8 s 内、缩略图哈希相同的
  卡片。两个完成事件在 UI 线程上按序处理，后到的一张一定能看见先到的那张。
- 只有当双胞胎已经在线上时才删除新副本；它还没到就先把这张挂上，等对方到达
  再合并——两种到达顺序最终都只有一张卡。
- worker 快路径仍按最长边 2048 解码后逐像素比较，允许 0.5% 像素每通道差 ≤ 8。

### 9.5 标注

- 图片卡片右键“标注”打开 §11 的标注窗口；不再有“先截图再标注”的快捷键链路。
- 打开时卡片从原位放大飞进编辑器，编辑器落地后才出现；编辑期间原卡片隐藏，行不重排。
  关闭（保存、取消、点击窗口外或失焦）时带标记的图缩回原槽位。
- 标注窗口保存时以**源图原始像素尺寸**输出 PNG，覆盖卡片当前指向的文件。
- 保存后重新解码该卡片缩略图，卡片留在原位、不新建副本；文件监听不会把这次
  写入当成新截图。
- 取消时文件保持原样。
- 外部程序（画图）保存覆盖原文件后，1 s 内自动刷新卡片缩略图。

## 10. 便签

- 来源：复制文字后按 `Ctrl+Alt+N`；剪贴板为空时弹托盘气泡提示。
- 存储：`%LOCALAPPDATA%\Pegline\Notes\便签 yyyy-MM-dd HHmmss.txt`，UTF-8 带 BOM、
  CRLF 换行；读取时容忍 BOM 与 LF/CRLF。
- 同一段文字再次触发 → 不新建，只把已有便签展示出来。
- 渲染：136×88 DIP，3 倍超采样（408×264），圆角纸片 + 右下折角 + 阴影。
  - 短文本（≤24 字且无换行）：≤12 字 16 px，否则 13 px，居中。
  - 长文本：11.5 px，行高 14.5，自动换行，末尾省略号。
  - 卡片摘要先去掉常见 Markdown 标记：标题/引用/列表前缀不显示，列表变成
    “• ”，任务变成 “[x] ”；正文里的 `**`、`` ` ``、链接语法等不落到卡片上。
- 颜色：4 色，记录在 `settings.ini` 的 `noteColor:<文件名>`。
- 悬停显示色板，点击换色并立即重绘。

### 10.1 WYSIWYG 便签编辑器

详细设计见 `docs/NOTE-EDITOR.md`；这里是用户可见行为的摘要：

- **入口**：线带放下后，最后一张卡右侧 12 DIP 起有一块不可见的入口区域。
  指针进入**工具范围**（整条线带和挂图周围约 12 DIP）时，入口大部分留在
  屏幕外，只在屏幕顶边露出**倾斜卡片（18°）的右下角 12 DIP**；入口命中区从
  顶边一直延伸到槽位底部。指针移到入口上，便签从屏幕外的同一位置、同一倾角
  快速落下并回正，**0.22 s** 后停在**理论挂点**——也就是
  最后一张卡右侧的下一个卡片槽位（与卡片同高）——并在那里以 ±3 DIP / 0.22 Hz
  缓慢上下浮动。这张便签**和绳上的挂图一样装在玻璃卡片里**：144×96 DIP 的
  圆角玻璃外框、4 DIP 白边，纸面（136×88 DIP）按图片的 `PHOTO_INSET` 内缩
  放在框内，阴影和边框都与图片卡片一致；纸面上方是一个墨色圆形加号图标，
  下面“新建便签”用与短便签正文相同的 16 DIP、半粗、墨色（随界面语言：
  New note / Nueva nota），整体跟着卡片一起倾斜。指针相对便签中心
  的距离和方向产生一股指向指针的拖拽力，与把便签拉回挂点的阻尼弹簧对抗：
  便签会滞后、轻微过冲后回正，带一点惯性，而不是贴着鼠标走；拖拽力有距离
  上限（30 DIP），便签不会被拉得满条跑。同一股指针力还让便签**绕自己的中心
  倾斜**：以中心为交点的十字线是零度线（十字线上和中心点都不倾斜），左上、
  右下象限顺时针，右上、左下象限逆时针；离中心越远角度越大（对角线方向
  120 DIP 外封顶 5°），越靠近中心越小。倾斜走一条与拖拽同响应、同阻尼的角
  弹簧，所以同样会滞后、轻微过冲后回正，飞出时同时回正。指针离开入口区域
  （热点外再留 24 DIP 余量）后便签沿 0.42 s 的曲线飞回上方消失；点击便签
  进入编辑器，飞向中央的飞行不画挂夹。入口内和便签上显示手形光标。
- **窗口**：屏幕中央 500×400 DIP，纸面 460×360 DIP；无标题栏、无按钮、
  无工具栏、无滚动条；纸面 + 1.5 DIP 玻璃边框 + 阴影；编辑窗口取得键盘焦点。
- **WYSIWYG**：源码（Markdown）是唯一真相；光标所在源码行显示原文（标记淡化
  到 45 % 墨色），其余行实时渲染标题、粗体、斜体、删除线、行内代码、代码块、
  列表、任务列表、引用、链接和分隔线。单换行就是换行，空行分段。
- **输入**：字符/IME 组合串、方向键、Home/End、Shift 选区、Ctrl+词移动、
  Backspace/Delete、Enter、Tab（4 空格）、Ctrl+A/C/X/V、Ctrl+Z/Y、
  Ctrl+B/I/反引号、鼠标拖选、双击选词、滚轮滚动；没有右键菜单。
- **提交**：点击纸面外、失焦、Esc、Ctrl+S、关闭窗口都提交。空文本：
  新建便签不写文件，**也不让窗口凭空消失**——纸面会缩小、带着随机方向的自转和
  横向/向上的初速度飞出，然后按重力自由落体掉出屏幕（约 0.9 s），编辑窗口在
  飞行层画出第一帧后才隐藏；已有便签把文件移进归档并取下卡片。非空：worker
  原子写原路径（新建则先创建文件），成功后刷新卡片；新建便签从编辑窗口飞回新
  卡片槽位，已有便签飞回原槽位，落地交接使用截图飞行的曲线与淡出。编辑期间
  线带保持放下；**已有便签的卡片在飞行的第一帧画出后隐藏**（`SetRehang`，行不重排），
  不会出现“编辑窗口和挂着的便签同时存在”；保存/取消后随返回飞行在槽位恢复。
  已有便签即使内容没变，点纸面外也播放同一条飞回动画，而不是让窗口原地消失。写盘失败时
  窗口保持打开、输入恢复、玻璃边框闪红 120 ms 并写 `error.log`。
- **归档**：卡片叉、右键“归档”、全部取下、容量淘汰都会把便签文件移进
  `%LOCALAPPDATA%\Pegline\Notes\Archive`，重名追加序号；文件不会进回收站。
  “保存到桌面”只复制，原文件留在 Notes，不归档。
- **关闭编辑器**：提交成功后关闭并释放 D3D/D2D 资源；应用退出时最多等 2 s
  完成一次提交，失败则记录日志后退出（v1 无崩溃草稿）。
- **兼容**：文件仍是 `.txt` + BOM + CRLF，WPF 版可以打开；旧便签按 Markdown
  解释。

## 11. 标注编辑器

- 入口：图片卡片右键“标注”；便签不进入这里，它的“编辑”打开 §10.1 的便签编辑器。
- 窗口：无边框、无标题栏、无窗口按钮的置顶浮窗（`WS_POPUP` + 透明背景）。整体是一张
  **放大的挂图**：白玻璃圆角相框（4 DIP 边、16 DIP 圆角）+ 顶部金属夹 + 一次性烘焙的
  阴影；照片按源图比例缩放到工作区的 88 %，1:1 为上限、不放大，最长边最多
  1400×1000 DIP（6K 截图不会要一张 5200 px 宽的交换链）。
- 工具栏不再是窗口内的一条黑条，而是围绕挂图外沿**漂浮的五个玻璃胶囊**，与窗口边缘
  留 26 DIP、与卡片留 26 DIP：
  - 上方三枚：工具（箭头/矩形/文字/马赛克）、6 色、3 档线宽（每条显示实际粗细）；
  - 下方两枚：撤销/重做、取消/保存。
  - 点在胶囊上但不在按钮上不结束编辑；点在其他空白处结束。
- 打开：从卡片的当前屏幕矩形**放大飞入**编辑器的卡片矩形（飞行窗口承载缩略图和挂夹），
  落地后编辑器才显示并取得焦点。编辑期间线带上的原卡片隐藏（`SetRehang`，行不重排），
  不再同时出现“编辑窗口 + 还挂着的卡片”。
- 关闭：
  - 点击编辑器窗口内、卡片与胶囊之外的空白，或窗口失去焦点 → **保存并飞回**；
  - Esc → 取消并飞回，文件保持原样；
  - Ctrl+S → 保存；Ctrl+Z / Ctrl+Y → 撤销/重做。
  - 返回飞行使用**带标记的预览图**（保存时渲染，最长边 720 px）；落地时原卡片已在槽位里
    显示新图。取消时使用原缩略图，卡片不刷新。
- 照片与标记先画进一张不透明卡片位图（保留 ClearType），再以圆角遮罩合成到透明窗口；
  胶囊文字画在窗口上，用灰度抗锯齿。
- 工具：箭头（箭头方向与尖端都跟随拖动，见 `docs/VISUAL-TESTS.md` §3.1）、矩形、文字
  （白色输入框 + 光标，IME 组合串/候选窗跟随）、马赛克（16 source px 块，最近邻）。
- 保存：按源图原始像素尺寸渲染 PNG（文字用灰度避免彩边），覆盖卡片文件；随后重建缩略图，
  不改动其他卡片。取消不改动文件。没画任何标记时关闭不重写文件，按取消处理。
- 标注窗口不参与线带的 `Ctrl+Alt+S` 截图链路；该链路已移除。

## 12. 托盘、快捷键、设置

### 12.1 托盘

- 图标：16 * 屏幕缩放像素，运行时绘制（§13）。
- 左键：显示/收起线带。
- 菜单：显示/收起绳子、把复制的文字挂成便签、便签快捷键…、全部取下、
  清空截图文件（N 个）…、接管截图（勾选）、打开截图文件夹、
  ——、音效（勾选）、开机启动（勾选）、——、退出。
- 不再提供“截图”和“截图快捷键”菜单项：截图后标注的入口改为图片卡片的右键“标注”。

### 12.2 快捷键

- 默认：便签 `Ctrl+Alt+N`，显示/隐藏 `Ctrl+Alt+T`（固定）。原来的截图 `Ctrl+Alt+S` 已移除。
- 设置窗口：直接按键录制；F1–F24、PrtScn 可单独使用；其余必须带修饰键。
- 冲突检查：不能与固定的 `Ctrl+Alt+T` 重复；被其他程序占用时提示。
- 支持“无快捷键”。

### 12.3 设置与数据

| 位置 | 内容 |
|:--|:--|
| `%APPDATA%\Pegline\settings.ini` | `key=value`：welcomed、catchOffered、catchClipboard、soundOff、noteKey、noteColor:\<文件名\> |
| `%APPDATA%\Pegline\pegged.txt` | 每行一个挂着的文件路径（不含正在掉落的） |
| `%LOCALAPPDATA%\Pegline\Screenshots` | 接管的截图 |
| `%LOCALAPPDATA%\Pegline\Notes` | 便签 .txt |
| `%LOCALAPPDATA%\Pegline\Notes\Archive` | 取下/归档的便签 .txt |
| `%APPDATA%\Pegline\error.log` | 异常 |
| `%APPDATA%\Pegline\trace.log` | 环境变量 `PEGLINE_TRACE=1` 或 `trace.on` 文件存在时 |
| `HKCU\...\Run` | 开机启动 |

**Rust 版必须继续读写这些格式**，用户可以来回切换两个版本。旧版留下的 `snipKey`
按“未知键”原样保留，但不再注册或显示。

### 12.4 音效

三个短音，44.1 kHz 单声道 16 bit，启动时合成并缓存，`PlaySound(SND_MEMORY)`：

- 挂上：0.18 s，1760 Hz + 3520 Hz，指数衰减。
- 取下：0.09 s，420 → 1800 Hz 扫频。
- 丢弃/清空：0.28 s，低通噪声。

## 15. 健壮性

- 单实例（命名互斥体 `Local\Pegline.SingleInstance`）。
- 未处理异常写 `error.log`，不让一个手势崩掉整个托盘程序。
- 所有文件操作失败都要静默降级（读不到就不挂、删不掉就保留并提示）。
- 解码/编码/比较/删除到回收站，一律不阻塞 UI 线程。
