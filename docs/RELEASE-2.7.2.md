# Pegline 2.7.2 发布说明

## 2.7.2 变更

**两处交接闪烁都修掉了：新建便签入口不再闪出“小半张便签”，丢弃空便签也不再先闪没再下落。**

- **复用的飞行窗口会留下上一段动画的末帧。** 飞行窗口闲置一段时间后只是隐藏（2×2），
  不动交换链；下一段飞行先在 UI 线程换好窗口位置，渲染线程稍后才重画，这中间的 1–2 帧
  DWM 会把旧画面按新尺寸拉伸、裁在左上角。普通飞行结束在透明、掉落结束在 2 % 透明，都看不见，
  只有**丢弃翻滚的末帧是不透明的**——它的“纸面出窗”判据在画之前执行，最后画出的那一帧纸面
  还在窗口底边之上。于是“新建 → 丢弃 → 30 s 内再新建”就闪出那块切片。
  现在三条动画离开循环前都先呈现一帧**全透明**，正常结束和被打断两条路径都做。
- **丢弃空便签的交接。** 翻滚在首帧 `Present` 之后立刻报告“首帧已交出去”，编辑窗口一收到就
  隐藏自己的纸面；而 `Present` 只是排队（默认延迟三帧），隐藏可能早 1–2 个 vblank，中间就是
  空帧。现在翻滚先 `DwmFlush()` 确认第一帧已被合成，再从首帧起保持原姿态约 **0.05 s**
  （60 Hz 三帧），然后把物理时钟重置到那一刻、以静止状态开始缩小自转下落。整个运动只是
  整体后移，缩小曲线、重力、初速度、自转一律没改。

点击到开始下落多约 0.05 s，但这三帧纸面停在编辑窗口刚消失的位置、大小和角度都没变，
读起来是“落了一下”而不是“点了没反应”。

## 验证

- 227 个 lib 测试 + 1 个 main 测试通过（新增 1 个：交接段保持编辑纸面、放手后从静止开始）；
  `cargo clippy --all-targets -- -D warnings` 与 `cargo fmt --check` 干净。
- 丢弃交接实测（release，200 % DPI，trace）：`tumble render start` → `tumble finished after
  60–62 frames, 0.90–0.92s`，墙钟 0.956–0.975 s；其中前 3 帧是交接段，真正运动的帧数与
  2.7.1 的 56–58 帧一致。
- `probe` 与 2.7.1 的独立 `git worktree` 构建做 A/B：`--mode=line` 59.97–60.10 fps、
  draw p50 0.743–0.783 ms、private 96.8–97.6 MB；`--mode=flight` 60.34–60.68 fps、
  private 94.2–94.5 MB。两侧一致，没有回退。
- 按用户要求，交接处的逐帧抓图（原计划的 S1–S4）没有做，改为人工目视确认。

## 已知限制

- 120 Hz、第二显示器和睡眠/唤醒仍未实测。
- 交接段保持的是编辑纸面的姿态，编辑器自己的 1.5 DIP 玻璃描边和 18 %／24 DIP 阴影不会跟着
  画到飞行层上：交接瞬间它们会消失。本版按计划跳过（另烘焙一套需要新的阴影图集，超出预算），
  由用户目视确认可接受。
- 另外三条飞行（截图、标注开、标注关）同样在“首帧交给合成器”时隐藏各自的来源，理论上也有
  早 1–2 个 vblank 的风险；它们从首帧起就在移动、盖住的是静止的卡片或编辑窗口，本版没有改动
  `run_flight` 报 `Started` 的时机（计划列为范围之外）。
- 合成鼠标事件（`mouse_event` / `SendInput`）在 200 % DPI 下进不到应用的 `WH_MOUSE_LL` 钩子，
  所以入口相关的动画目前没法脚本化回归。

## 安装

1. 在本页 Release 资产中下载 **`pegline.exe`**（单文件，无需解压）。
2. 把它放到任意目录，双击运行；程序从托盘启动。
3. 按 **Ctrl+Alt+K** 截图，截图会挂到屏幕顶部的晾衣绳上。

设置、便签和线序保存在 `%APPDATA%\Pegline` 与 `%LOCALAPPDATA%\Pegline`。
