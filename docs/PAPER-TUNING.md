# 纸片物理调参：逐帧追踪与绘图

2.6.0 的纸片摆动不是关键帧，而是由尺寸、速度和空气阻力共同决定的积分结果。
只靠截图看 2–3 帧很难判断“过冲几次、多久停、竖卡是不是更兜风”，所以提供
**B 方案**：让真实场景逐帧写 CSV，再用一个只用标准库的脚本画角度、角速度和
线速度，并算出峰值、过零和停稳时间。

这比另做一个带滑杆的调试窗口便宜得多，也不会有“简化画布和真实场景不一致”的
风险。另有一个单文件 HTML 滑杆版，用于先看手感；逐帧数值仍以本页的 CSV 为准。

## 交互式 HTML 调参器（先看手感）

`tools/paper-sim.html` 是单文件、无外部依赖的 SVG 调参器：直接用浏览器打开，
拖动卡片顶部的夹子，松手看摆动；右侧滑杆实时改参数，底部显示角度/目标与
角速度曲线，以及峰值、过零和停稳时间。

- 预设：`Rust 基线`（当前代码值）、`更强空气`、`无空气`、`纸片`。
- 当前 `更强空气` 预设是空气倍率 1.55、线性阻尼 0.72/0.28、二次阻力 0.18/0.2、
  风 2.8e-5；乘完等于 Rust 的 1.116/0.434、0.279/0.31、4.34e-5。滑杆上的 0.2 是
  预设内增量，0.2 × 1.55 = 0.31 才是 Rust 的有效值。
- `空气倍率` 同时缩放线性阻尼、二次阻力和风扭矩；先把它拉到 1.5–2.0 看空气的
  存在感，再分别调 `线性阻尼 ζ`、`二次阻力`、`风扭矩增益`。
- `宽/高` 改卡片尺寸；`高宽比归一`、`高宽比阻尼增量`、`高宽比阻力增量` 控制
  竖卡加成。
- `轻弹` 给一个水平初速度，不用鼠标也能看衰减；`复制参数` 把当前滑杆值复制成
  JSON；`暂停`/`重置` 便于对比。
- 它只模拟一张卡和绳子，不包含挤压/交换；Rust 场景里的参数以 CSV 为准。
- 滑杆值是调试倍率；Rust 侧对应 `PEGLINE_PAPER_DAMPING`/`DRAG`/`WIND`/`ASPECT`，
  改完用上面的 trace 命令复核。

## 快速开始

```powershell
pwsh -NoProfile -File tools/paper-trace.ps1
python tools/paper-plot.py target/paper-trace.csv -o target/paper-trace.html
```

第一条命令会：

1. 以 `--demo` 启动 `target\release\pegline.exe`。注意 `--demo` 仍会加载真实
   `pegged.txt`；要得到干净的三卡 trace，先把真实线隔离/清空（不要在正式使用中
   覆盖用户数据）；
2. 等 3.4 s，把指针移到第一张卡的夹子 `(1614,87)`（200% DPI 的物理坐标）；
3. 按下左键，分 10 步向右拖 200 px（每步 20 px、间隔 45 ms），松开；
4. 再等 2.5 s，停止应用；
5. 把逐帧数据写到 `target/paper-trace.csv`。

第二条命令生成 `target/paper-trace.html`（角度/目标、角速度、线速度三块 SVG），
并在终端打印峰值、过零、停稳等指标。

脚本参数：

```powershell
pwsh -NoProfile -File tools/paper-trace.ps1 `
  -Output target/paper-trace.csv `
  -PinX 1614 -PinY 87 -TargetX 1814 `
  -Damping 1.0 -Drag 0.24 -Wind 3.5e-5 -Aspect 1.2
```

`-PinX/-PinY/-TargetX` 是物理像素；换 DPI 或显示器时按实际夹子位置调整。
`-Damping/-Drag/-Wind/-Aspect` 只对本次进程设置对应的 `PEGLINE_PAPER_*` 环境变量。

## 环境变量

这些变量在进程内只读取一次（`OnceLock`），改完要重启应用/脚本。

| 变量 | 默认 | 含义 |
|:--|--:|:--|
| `PEGLINE_PAPER_TRACE` | 未设置 | CSV 输出路径；设置后场景每帧写一行 |
| `PEGLINE_PAPER_DAMPING` | 1.116 | 线性阻尼基线；竖卡再加 `0.434·tall` |
| `PEGLINE_PAPER_DRAG` | 0.279 | 二次阻力基线（1/度）；竖卡再加 `0.31·tall` |
| `PEGLINE_PAPER_WIND` | 4.34e-5 | 相对风增益基线；竖卡再乘 `0.7+0.6·tall` |
| `PEGLINE_PAPER_ASPECT` | 1.2 | `tall=clamp((aspect−1)/aspect_norm, 0, 1)` 的归一化 |

`PEGLINE_PAPER_TRACE` 打开时，`src/scene/trace.rs` 在渲染线程用 `BufWriter`
逐行写并 flush；写失败会关闭追踪并记日志，不会影响拖拽。生产运行不要设置它。

## CSV 列

| 列 | 单位 | 含义 |
|:--|:--|:--|
| `t` | s | 进程启动后的时间（`now_seconds`） |
| `id` | — | 卡片 id |
| `grabbed` | 0/1 | 当前帧被夹子拖拽 |
| `hop` | 0/1 | 正在做交换小跳 |
| `release` | 0/1 | 松手后的归位弹簧阶段 |
| `x` / `vx` | DIP, DIP/s | 卡片中心与水平速度 |
| `drop` / `vy` | DIP, DIP/s | 挂点相对绳子的下拉与速度（Y 激励来源） |
| `angle` | ° | 实际摆角（Direct2D 正角 = 顺时针，底边向左） |
| `omega` | °/s | 摆角速度 |
| `target` | ° | `atan(a_x/g_eff)`，±6° |
| `ax` / `ay` | DIP/s² | 水平/垂直加速度（限 ±6000） |
| `g_eff` | DIP/s² | `clamp(35500−ay, 0.25g, 1.75g)` |
| `wind` | °/s² | 压心相对风扭矩，已限 ±6000 |
| `flex` | ° | 视觉剪切，±1.2° |
| `swap_dir` | −1/0/+1 | 最近一次交换方向 |

## 读图与指标

`tools/paper-plot.py` 默认选被拖过的卡（第一条 `grabbed=1`，否则取 |omega| 最大），
减去首行时间后画图；`release` 行之前画一条虚线。指标定义：

- **峰值 |angle| after release**：松手后的最大摆角，越大越“甩”。
- **zero crossings after release**：松手后角度变号次数；包含小角度抖动，
  不等于肉眼看到的来回次数。
- **settle**：最后一次同时满足 `|angle| ≤ 0.1°` 且 `|omega| ≤ 0.5°/s` 的时间；
  这是“看起来停住”的保守上限。
- **max |omega|**：角速度峰值，判断是否“抽”得太快。
- **max |vx| / |vy|**：卡片平移速度峰值，帮助区分“摆得厉害”还是“拖得太快”。

**旧基线**（0.45/0.05 时期；200% DPI，三张 480×270 / 270×480 / 300×300 的卡）。当前“更强空气”预设还没有可靠的新 trace 数值基线，用户将手测；不要把下表当成当前参数的结果：

| 指标 | 值 |
|:--|--:|
| 卡 id | 7 |
| trace 时长 / 松手 | 6.76 s / 4.24 s |
| 松手后峰值 | 5.50° |
| 松手后过零 | 7 次（含小角度抖动） |
| 停稳 | 817 ms |
| max omega | 97.5°/s |
| max(abs(vx)) / max(abs(vy)) | 3444 / 311 DIP/s |

旧基线里的卡是横卡（`aspect≈0.56`，`tall=0`）；竖卡会按 `tall` 自动更重、更兜风。当前预设的数值请用 HTML 调参器或重测的 trace。

## 模型回顾

- 每卡摆长 `L_eff=(w²/12+h²/3)/(h/2)`（60–220 DIP），`ω=sqrt(g_eff/L_eff)`。
- 摆角方程：`θ'' = ω²(target−θ) − 2ζωθ' − drag·|θ'|θ' + wind`，
  240 Hz 子步、半隐式欧拉。
- 目标 `target=atan(a_x/g_eff)`，`a_x` 取 X 弹簧速度差分；死区 300 DIP/s²。
- 高宽比：`aspect=h/w`，`tall=clamp((aspect−1)/aspect_norm,0,1)`；
  `ζ=1.116+0.434·tall`，`drag=0.279+0.31·tall`，`wind_gain=4.34e-5·(0.7+0.6·tall)`。
- 相对风：压心 `r=h/2`，点速度 `v_p=(vx−rωcosθ, vy−rωsinθ)`，
  `wind=wind_gain·|v_p|·(v_p·(cosθ,sinθ))·r`。匀速右移时 `wind>0`，卡片略微向后倒。
- 柔性：`flex.target=0.006·ω`，±1.2°，弹簧 0.12/0.55；`paint` 在旋转前绕
  `(75,0)` 做剪切，顶边和夹子不动。
- 只有被拖、交换小跳、松手归位中的卡参与；飞行/回挂中的摆角和柔性归零。

## 调参对照

| 现象 | 先调 |
|:--|:--|
| 停得太快、像铁块 | `PEGLINE_PAPER_DAMPING` 降到 0.80–0.95；`DRAG` 降到 0.18–0.24 |
| 来回摆太多次 / 小角度抖 | `DAMPING` 升到 1.20–1.35；`DRAG` 升到 0.32–0.38 |
| 大摆衰减太快 | `DRAG` 降到 0.24–0.26 |
| 竖卡和横卡手感一样 | 检查 `ASPECT`；`tall` 由卡片实际 `h/w` 决定，`ASPECT` 越小竖卡加成越大 |
| 匀速拖动时向后倒太多 | `WIND` 降到 3.5e-5–4.0e-5 |
| 匀速时几乎不后倒 | `WIND` 升到 5.0e-5–5.5e-5 |
| 松手急停、摆得太凶 | 松手弹簧在代码里（`RELEASE_RESPONSE/DAMPING`，当前 0.46/0.80），不是环境变量 |
| 想换每卡摆长 | `L_eff` 公式在 `effective_length`；先用不同尺寸的卡看周期，不要用环境变量硬改 |

调完一轮用同一条命令重跑，把 `target/paper-trace.html` 和上一轮对比；截图只做
最终手感确认，不作为数值依据。

## 限制

- 空气阻力是经验模型，不是 `0.5ρCdA`：没有平移阻力对 `x/drop` 的反馈、升力、
  涡脱落、附加质量，也没有逐顶点弯曲。风阻系数是调出来的。
- `PEGLINE_PAPER_*` 只影响摆角/柔性，不影响 X/Y 弹簧、挤压阈值和交换手感。
- 追踪在渲染线程写文件，只用于调参；不要在正式使用中常开。
- 脚本按 200% DPI 的物理坐标写死；其他 DPI 请改 `-PinX/-PinY/-TargetX`。
- `--demo` 仍会加载真实 `pegged.txt`；trace 前要隔离/清空真实线，否则会抓到真实卡。当前“更强空气”预设的 trace 基线尚未重测。
- 120 Hz、第二显示器、睡眠/唤醒仍未实测。
